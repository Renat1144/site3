# Turkey Signature

Премиальный одностраничный WordPress-сайт об авторских путешествиях по Турции. Контент, шапка и подвал собраны из блоков Gutenberg и редактируются через **Страницы** в обычной админке WordPress.

## Локальный запуск

Требуется установленный и запущенный Docker Desktop.

```sh
./local-setup.sh
```

После первого запуска скрипт автоматически создаст локальные пароли, установит WordPress и активирует тему.

- Сайт: http://localhost:8082/
- Админка: http://localhost:8082/wp-admin/
- Локальные данные для входа: `.local-admin.txt`

Файлы `.env`, `.local-admin.txt`, `wp-config.php`, база данных, загрузки WordPress и архивы переноса не публикуются в Git.

Подробности: [LOCAL_SETUP.md](LOCAL_SETUP.md).

## Редактирование страниц

- Главная: **Страницы → Главная**.
- Новые самостоятельные разделы сайта создаются через **Страницы → Добавить страницу**.
- Новая страница получает общую шапку и подвал, а также стартовую секцию в стиле сайта.
- Блоки не заблокированы: их можно добавлять, удалять, копировать и переставлять.
- «Внешний вид → Редактор» нужен только для технической настройки шаблонов и общих частей темы.

## Статическая версия для GitHub Pages

После изменений в WordPress обновите статический снимок:

```sh
./script-static-export.sh
```

Скрипт создаёт корневой `index.html` из текущей публичной страницы WordPress. GitHub Pages публикует этот файл, а WordPress продолжает работать локально и остаётся главным источником редактируемого контента.

При запуске `Закончить работу.command` или `Закончить работу.cmd` статический снимок обновляется автоматически перед созданием приватного архива переноса.
