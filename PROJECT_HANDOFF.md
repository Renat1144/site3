### Важные решения и ограничения

- WordPress является главным редактируемым источником; статический `index.html` — снимок для GitHub Pages.
- Публичная страница и редактор Gutenberg должны оставаться единой реализацией и визуально совпадать.
- В GitHub нельзя добавлять закрытые архивы, `.env`, `wp-config.php`, локальные логины и дампы базы.
- Форма заявки пока остаётся обозначенным местом-заполнителем: адресат заявок и окончательный текст согласия не предоставлены.
- Даты и стоимость не выдумывались: в интерфейсе оставлены честные значения «уточняются». Для завершения коммерческой части нужны реальные даты, цена, получатель заявок и юридический текст согласия.
- Движение по странице реализовано прогрессивно: без JavaScript содержимое остаётся доступным, а при `prefers-reduced-motion` автоматические и scroll-driven эффекты отключаются.
- Миграция v2 помечается опцией WordPress `turkey_signature_homepage_redesign_v2`; менять вручную эту опцию не требуется.
- Миграция уточнений v3 помечается опцией `turkey_signature_homepage_refinement_v3`, сохраняет ревизию страницы и применяется только к неизменённому результату v2.
- Миграция очистки v4 помечается опцией `turkey_signature_homepage_cleanup_v4`, применяется только к неизменённому результату v3 и при повторном запуске не создаёт новую ревизию.
- Миграция упрощения v5 помечается опцией `turkey_signature_homepage_simplification_v5`, применяется только к неизменённому результату v4 и при повторном запуске не создаёт новую ревизию.
- Миграция команды v6 помечается опцией `turkey_signature_homepage_team_v6`, применяется только к неизменённому результату v5 и при повторном запуске не создаёт новую ревизию. После v6 главную следует считать новым исходным состоянием для последующих защищённых миграций.
- Перед v5 создана закрытая проверенная копия `backups/homepage-refinement-before-20260802-0005/`: дамп базы, ZIP темы и chroma-key исходник логотипа. Каталог закрыт правилом `backups/` и не должен попадать в Git.
- Сырой снимок заменённого тома сохранён в `backups/volume-snapshots/`; страховочный архив свежего состояния перед импортом сохранён в `backups/`. Оба каталога закрытые и не должны попадать в Git.
