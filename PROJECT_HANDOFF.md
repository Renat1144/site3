# Передача контекста проекта Turkey Signature

Этот файл хранит актуальное состояние проекта для продолжения работы в новой сессии или на другом устройстве. Смысловую часть обновляет Codex после каждой задачи, изменяющей проект. Кнопка **«Закончить работу»** дописывает внизу безопасный технический снимок.

Не добавлять сюда пароли, токены, содержимое `.env`, `wp-config.php`, дампы базы и персональные данные.

### Важные решения и ограничения

- WordPress является главным редактируемым источником; статический `index.html` — снимок для GitHub Pages.
- Публичная страница и редактор Gutenberg должны оставаться единой реализацией и визуально совпадать.
- В GitHub нельзя добавлять закрытые архивы, `.env`, `wp-config.php`, локальные логины и дампы базы.
- Форма заявки пока остаётся обозначенным местом-заполнителем: адресат заявок и окончательный текст согласия не предоставлены.
- При первом переходе на Windows нужно сначала обновить локальную папку проекта из GitHub, а затем нажать **«Начать работу»**. После этого содержимое проекта продолжит синхронизироваться через единый приватный архив.
